# Independent verse-marker baseline

The original PDF1 first-ayah marker has a multilobed ornamental outer ring and a Bengali1inside; the separate Arabic stop sign is above it. The reusable treatment must retain only the outer frame and render each current source numeral as real Bengali text. Keep the existing first-ayah marker/stop unchanged.

The JSON baseline records the expected numeral sequence from all7draftpage datasets and hashes of data, annotation and Arabic-font assets. Final review checks1/2/3digit fit, mobile rendering, actual text selection and preservation of body/annotation appearance. It does not approve exact original marker outlines for every number or full-Quran fidelity.
