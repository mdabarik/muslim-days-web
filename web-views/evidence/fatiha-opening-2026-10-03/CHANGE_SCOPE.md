# Fatiha opening correction

The user identified a mismatch in the letters, harakat and upper instructional signs of the first printed ayah beginning اَلْحَمْدُ. The previous symbol repair replaced missing instructional glyphs but left the Arabic body in Amiri, which does not reproduce the scanned edition's shapes.

This change uses the previously source-reviewed four fully vowelled word contexts in a real outline font. The original Arabic Unicode remains in visible HTML text. The font contains the source word outlines, including the source-shaped sukun and other harakat; it must never be applied to unlisted word contexts. The five instructional signs use source outlines and scale inside their source word wrappers. These are observed relative positions, not newly certified semantic letter IDs.

The source's Arabic/Bengali surah heading and metadata are also moved before the separate, unnumbered basmala. This fixes an independent ordering error. The title and basmala typography remain drafts.

No original source candidate is edited, and no full-page, full-surah, or whole-Quran acceptance is granted by this change. The remaining Arabic words still use the existing fallback typeface. Flutter is untouched. Source scans are used only as local review evidence; the website contains selectable text and outline fonts, without source images, SVG text, or hidden text overlays.
